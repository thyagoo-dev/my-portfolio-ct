# Bibliotecas (Libraries)

Este projeto utiliza um conjunto de bibliotecas modernas para garantir performance, interatividade e uma experiência de usuário premium.

## 🛠️ Core (Núcleo)
- **React 19**: Biblioteca principal para construção da interface.
- **React Router Dom 7**: Gerenciamento de rotas e navegação SPA.
- **TypeScript**: Superset de JS para tipagem estrita e segurança do código.

## 🎨 Animação e Interatividade
- **Framer Motion**: Utilizada para animações de componentes, transições de página e estados interativos.
- **GSAP (GreenSock)**: Focada em animações de scroll (`ScrollReveal`) e micro-interações de alta performance.
- **Lottie (DotLottie)**: Integração de animações vetoriais leves para ícones e feedbacks visuais.

## 🧊 Elementos 3D
- **Three.js**: Engine fundamental para renderização 3D.
- **React Three Fiber (R3F)**: Renderizador React para Three.js, utilizado no background e elementos hero.
- **@react-three/drei**: Coleção de helpers úteis para acelerar o desenvolvimento com R3F.

## 💅 Estilização e UI
- **Tailwind CSS 4**: Framework utilitário para estilização rápida e responsiva.
- **React Icons**: Conjunto de ícones (Feather Icons e outros) usados em todo o projeto.

## 🌍 Globalização
- **i18next**: Framework de internacionalização.
- **react-i18next**: Integração oficial do i18next com React.
- **i18next-browser-languagedetector**: Detecta automaticamente o idioma do navegador do usuário.
