# Stack Tecnológica (Tech Stack):

A stack deste projeto foi selecionada para criar uma ponte entre a robustez do desenvolvimento Backend e a sofisticação do Frontend moderno.

## 💻 Linguagens e Frameworks:

### Frontend:

- **React (v19)**: Escolhido pela sua flexibilidade e ecossistema robusto.
- **Vite**: Ferramenta de build extremamente rápida que substituiu o CRA (Create React App).
- **TypeScript**: Garante que o projeto seja escalável e livre de erros comuns de tipagem.

### Estilização:

- **CSS3 Moderno**: Uso extensivo de Variáveis CSS (Custom Properties) para temas dinâmicos.
- **Tailwind CSS 4**: Utilizado para layout responsivo e utilitários rápidos.
- **CSS Modules / Raw CSS**: Para componentes que exigem controle total sobre a estética "Premium".

## 🛠️ Ferramental de Desenvolvimento:

- **Git**: Controle de versão.
- **NPM**: Gerenciador de pacotes.
- **ESLint/Prettier**: Padronização e qualidade de código.

## 🧪 Metodologia e Padrões:

- **Component-Driven Development**: Construção de interfaces a partir de componentes pequenos e reutilizáveis.
- **Responsive-First**: Design adaptado desde dispositivos mobile até telas ultra-wide.
- **Clean Architecture (Frontend)**: Separação clara entre Lógica de Negócio (hooks/data), Tipagem (types) e Visual (components).
