Descrição

O presente projeto foi desenvolvido com o intuito de criar um portfólio pessoal que sirva como uma vitrine profissional para apresentar minhas habilidades, projetos e experiência na área de desenvolvimento web.

Detalhes do Projeto

  • Desafio: Criar uma interface em que fosse totalmente interativa e que proporcionasse uma experiência agradável ao usuário.
  • Solução: Desenvolvimento de um portfólio pessoal utilizando HTML, CSS, JavaScript e Bootstrap, garantindo responsividade e interatividade.
  • Impacto: Aumento da visibilidade e reconhecimento profissional.

Arquitetura

Frontend -> API -> Banco de Dados

Stack e decisões

  • Autenticação: sessão ou JWT conforme escopo e perfil de acesso.
  • Back-end: regras de negócio isoladas em serviços para facilitar manutenção.
  • Deploy: Docker para padronizar ambiente e Nginx como proxy reverso.
  • Banco: modelagem relacional focada em integridade e performance.

Tecnologias Usadas

HTML5
CSS3
JavaScript
Bootstrap
