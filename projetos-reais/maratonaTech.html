Maratona Tech

Plataforma web para gestão de eventos de pitch.

Fotos do Projeto

Descrição

Maratona Tech é uma plataforma web desenvolvida para gestão de eventos de pitch, permitindo cadastro de eventos, pitchs, usuários participantes e votação online. O objetivo é oferecer um ambiente seguro, simples e escalável para competições, hackathons e maratonas de tecnologia.

Detalhes do Projeto

  • Desafio: Gerenciar eficientemente os eventos de pitch e a participação dos usuários.
  • Solução: Desenvolvimento de uma plataforma web que centraliza e organiza os eventos, pitchs e votações online.
  • Impacto: Melhoria na gestão dos eventos e aumento da participação dos usuários.
