Foi um sistema desenvolvido para organização de recursos e informações da GRE Floresta.

Fotos do Projeto

Descrição

Sistema completo para gestão de hospedagens e eventos desenvolvido com Django. O projeto inclui funcionalidades como cadastro de usuários, gerenciamento de reservas, controle de eventos e uma interface administrativa robusta. O sistema foi projetado para ser escalável e fácil de usar, atendendo às necessidades específicas da GRE Floresta.

Detalhes do Projeto

  • Desafio: Gerenciar eficientemente os recursos e informações da GRE Floresta.
  • Solução: Desenvolvimento de um sistema completo para gestão de hospedagens e eventos, incluindo cadastro de usuários, gerenciamento de reservas e controle de eventos.
  • Impacto: Melhoria na organização e eficiência da gestão de recursos e informações da GRE Floresta.

Arquitetura

Frontend -> API -> Banco de Dados

Stack e decisões

  • Autenticação: sessão ou JWT conforme escopo e perfil de acesso.
  • Back-end: regras de negócio isoladas em serviços para facilitar manutenção.
  • Deploy: Docker para padronizar ambiente e Nginx como proxy reverso.
  • Banco: modelagem relacional focada em integridade e performance.
