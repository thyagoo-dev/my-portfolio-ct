Vk Software

Esse é um site que foi criado para divulgação da empresa Vk Software e seus serviços.

Fotos do Projeto

Descrição

Vk Software é uma plataforma web desenvolvida para divulgação da Vk Software e seus serviços. O sistema oferece informações detalhadas sobre a empresa, seus projetos e serviços, proporcionando uma experiência informativa e acessível para os usuários.

Detalhes do Projeto

  • Desafio: Divulgar eficientemente os serviços e projetos da Vk Software.
  • Solução: Desenvolvimento de uma plataforma web que centraliza e organiza as informações sobre a empresa, seus projetos e serviços.
  • Impacto: Melhoria na comunicação e acessibilidade das informações para os usuários.

Arquitetura

Frontend -> API -> Banco de Dados

Stack e decisões

  • Autenticação: sessão ou JWT conforme escopo e perfil de acesso.
  • Back-end: regras de negócio isoladas em serviços para facilitar manutenção.
  • Deploy: Docker para padronizar ambiente e Nginx como proxy reverso.
  • Banco: modelagem relacional focada em integridade e performance.
